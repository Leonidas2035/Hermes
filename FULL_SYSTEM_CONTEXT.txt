2. ДЕТАЛЬНИЙ АУДИТ ФАЙЛІВ ТРЕЙДИНГОВОГО КОНТУРУ (/home/layman/.hermes/quantumedge_analysis/)
-------------------------------------------------------------------------------

[trader.py]
- РОЛЬ: Головний торговий оркестратор системи.
- ПРИЗНАЧЕННЯ: Запускається кроном кожні 15 хвилин. 
  1. Збирає ринкову аналітику через market_analysis.py.
  2. Формує мульти-активний промпт (XRP, BTC, SOL + крос-пари BTC/SOL, BTC/XRP).
  3. Включає протокол розторгування «Замка» (Hedged Lock Resolution) та адаптивну стратегію SOL (DCA Scalp).
  4. Викликає хмарний ШІ Google Antigravity через CLI команду `agy --model "Gemini 3.6 Flash (Low)"`.
  5. Парсить згенерований ШІ JSON-блок торгових команд та виконує їх через tools/qe_trade.py.
  6. Формує лаконічний HTML-звіт і надсилає його в Telegram через Bot API.
- ЗВ'ЯЗКИ: Залежить від market_analysis.py, tools/qe_trade.py, .env, agy CLI.

[market_analysis.py]
- РОЛЬ: Аналітичний мозок системи (Трейдер-Маркет-Мейкер).
- ПРИЗНАЧЕННЯ: Зчитує дані індикаторів та біржі, проводить аналіз:
  - Раннього виявлення зміни тренду (MACD-перелом, Bollinger Squeeze, RSI дивергенції, LH/LL swing structure).
  - Маніпуляцій стаканом (spoofing, absorption, imbalance, стіни ордерів).
  - Макро-динаміки BTC/SOL/XRP та розрахунок співвідношень крос-пар BTC/SOL та BTC/XRP.
  - Оцінки новинного фону та рейтингу TradingView.
- ЗВ'ЯЗКИ: Залежить від indicators.py, market_data.py.

[market_data.py]
- РОЛЬ: Прямий збирач біржових даних у реальному часі.
- ПРИЗНАЧЕННЯ: Отримує свіжі свічки (klines), funding rate, open interest, тикери та стакан ордерів для BTC, SOL, XRP напряму з біржі BingX VST через бібліотеку CCXT.
- ЗВ'ЯЗКИ: Використовує ключі з .env, підключається до BingX VST Sandbox.

[indicators.py]
- РОЛЬ: Математичний блок технічного аналізу.
- ПРИЗНАЧЕННЯ: Обчислює індикатори MACD, Bollinger Bands, RSI, EMA, ATR, trend score для pandas DataFrames.

[tools/qe_trade.py]
- РОЛЬ: Виконавчий механізм торгових ордерів.
- ПРИЗНАЧЕННЯ: Приймає CLI-команди (`snapshot`, `place`, `market`, `cancel`, `set_sl`) з підтримкою специфікації монети (XRP, BTC, SOL) і торгує на BingX VST через CCXT.
- ЗВ'ЯЗКИ: Зчитує credentials з .env, надсилає ордери в REST API BingX.

[.env]
- РОЛЬ: Центральне сховище конфігураційних змінних та ключів доступу.
- ПРИЗНАЧЕННЯ:
  - BINGX_TESTNET_API_KEY / BINGX_TESTNET_SECRET: ключі для торгової біржі.
  - TELEGRAM_BOT_TOKEN / TELEGRAM_CHANNEL_ID: токен та чат-ID для відправки статус-звітів.
  - AGY_MODEL="Gemini 3.6 Flash (Low)": вибір моделі ШІ для виконання рішень.

[trader_state.json]
- РОЛЬ: Збереження поточного стану виконання (State Management).
- ПРИЗНАЧЕННЯ: Містить номер поточного циклу (cycle #423+), останій ринковий біас та сумарні метрики.

[trader_journal.jsonl]
- РОЛЬ: Журнал аудиту всіх виконаних угод та дій (Audit Log).
- ПРИЗНАЧЕННЯ: Логує у форматі JSON Lines кожне відкриття, закриття, виставлення лімітки, PnL та параметри виконання.

[venv/]
- РОЛЬ: Ізольоване середовище Python 3.10+.
- ПРИЗНАЧЕННЯ: Містить усі необхідні бібліотеки (`ccxt`, `pandas`, `python-dotenv`, `requests`).

-------------------------------------------------------------------------------
4. ІНСТРУКЦІЯ ДЛЯ МІГРАЦІЇ НА НОВИЙ СЕРВЕР
-------------------------------------------------------------------------------
1. Скопіювати папки:
   - `~/.hermes/quantumedge_analysis/` (весь трейдинговий код, `.env`, `venv`).
   - `~/.gemini/` (для збереження токенів авторизації Antigravity та файлів settings.json).
2. На новому сервері перевірити працездатність Python venv:
   `/home/layman/.hermes/quantumedge_analysis/venv/bin/python3 -c "import ccxt, pandas; print('OK')"`
3. Запустити тестовий торговий цикл:
   `/home/layman/.hermes/quantumedge_analysis/venv/bin/python3 /home/layman/.hermes/quantumedge_analysis/trader.py`
4. Налаштувати фоновий крон-таймер на 15 хвилин:
   `schedule(CronExpression="*/15 * * * *", Prompt="Run trader.py cycle")`
