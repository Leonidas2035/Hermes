# QUANTUMEDGE TRADING SYSTEM — CORE V4.0 RULES

## 🛡️ HERMES DNA & PYTHON-LEVEL RISK GUARDRAILS

### 1. 🚨 Margin Lock (Захист Маржі)
- **Умова:** Вільна маржа < 10% (`Free Margin / Total Balance < 0.10`).
- **Дія:** Відкриття нових однонаправлених лонгів/шортів **БЛОКУЄТЬСЯ** на рівні `qe_trade.py` (`MARGIN_PROTECTION_TRIGGERED`).
- **Виняток:** Дозволено відкриття контр-позицій (хеджування) для зменшення сукупного ризику.

### 2. ⛔ No-Loss Lock (Захист від збитків)
- **Умова:** Позиція має від'ємний `uPnL < 0`.
- **Дія:** 100% закриття по маркету **БЛОКУЄТЬСЯ** (`FULL_LOSS_REALIZATION_DENIED`).
- **Часткове скорочення:** Дозволено часткове скорочення (максимум до 50% від об'єму position `qty`).
- **Recovery Ledger:** Зафіксований частковий збиток автоматично записується у `runtime/recovery_ledger.json`.

### 3. 🎯 ROI Gates (Блокування передчасного профіту)
- **Умова:** `uPnL > 0`.
- **Правила:**
  - **SOL (Swing strategy):** Закриття позиції / TP дозволено тільки при `ROI >= 30.0%` (`ROI_GATE_DENIED`).
  - **XRP (DCA strategy):** Закриття / TP дозволено при `ROI >= 1.5%`.
  - **BTC (Hybrid strategy):** Закриття / TP дозволено при `ROI >= 1.5%`.

### 4. 🧠 Session Memory (Пам'ять Сесій)
- Не скасовувати лімітні ордери циклічно, якщо відхилення ціни не перевищує `> 2%`.

## ⚡ ДВОНАПРАВЛЕНА ТОРГІВЛЯ ТА ТЕПЛОВА КАРТА ЛІКВІДАЦІЙ

1. **Bi-Directional Execution:** Працювати дозволено у ДВІ сторони (LONG та SHORT). Основна позиція за трендом, але швидкі скальпи (Quick Scalps) відкриваються на екстремумах.
2. **Liquidation Heatmap Magnet Strategy:**
   - Після зняття шорт-ліквідності (наприклад, над $65,740), головним магнітом стає великий пул протилежних лонг-ліквідацій (наприклад, $64,256 на $58M).
   - Швидкі розворотні скальпи відкриваються для захоплення імпульсу до цього магніту з метою швидкого вивільнення маржі під наступні трендові входи.

## 🔄 RECOVERY LEDGER & AVERAGE DOWN

При отриманні сигналу `RECOVERY_AVERAGE_DOWN` у `market_analysis.json`:
1. Усереднення проводиться на розвороті тренду.
2. Нова ціна Take-Profit автоматично вираховується за формулою:
   `New TP = EntryPrice + (Accumulated Realized Loss / Position Size) + Min Target ROI`
3. Закриття за новим TP повністю покриває минулий частковий мінус і приносить чистий прибуток.
