⚡ ПРАВИЛО ЧАСТКОВОГО СКОРОЧЕННЯ ТА ПЕРЕЗАХОДУ (PARTIAL REDUCTION & RE-ACCUMULATION):
- Повне закриття збиткової позиції в мінус СУВОРО ЗАБОРОНЕНО.
- Проте, ШІ ДОЗВОЛЕНО частково скорочувати (на 20%–40%) збиткову ногу біля проміжних опорів чи при виснаженні імпульсу для зниження просідання, за обов'язкової умови:
  👉 Негайно виставити сітку перезаходу/добору (Re-entry DCA Grid) за вигіднішою ціною (нижче для LONG, вище для SHORT).
  👉 Прибуток від перезаходу за вигіднішою ціною повинен повністю ПЕРЕКРИТИ фіксований збиток від часткового скорочення та вивести ногу в сумарний плюс!

⚡ ТИМЧАСОВИЙ АГРЕСИВНИЙ РЕЖИМ (АМЕРИКАНСЬКА СЕСІЯ):
- Обмеження маржі (< 30%) тимчасово знято для тестування активного стилю торгівлі та вивчення імпульсних результатів під час Американської сесії.
- ШІ здійснює активні ринкові та лімітні входи (Market Buy, Dynamic Limit DCA, Counter SHORT), ловить пробої тренду та розганяє прибутковість.

1. Trigger Condition (Умови входу, Двонаправлена торгівля та Теплова карта ліквідацій)
- **Двонаправлена торгівля (Bi-Directional Trading):** Торгівля здійснюється в ОБІДВІ сторони (LONG та SHORT). Основна позиція будується за глобальним трендом згідно з графіком (1h/15m), а контр-трендові швидкі скальпи (Quick Scalps) відкриваються на екстремумах.
- **Liquidation Heatmap Magnet Strategy:** Рішення про контр-трендовий шорт/лонг приймаються на основі теплової карти ліквідацій. Приклади: після зняття шорт-ліквідності (наприклад, $65,740), головним ціновим магнітом стає великий пул протилежних ліквідацій (наприклад, $64,256 на $58M), що обґрунтовує агресивний контр-скальп по всьому ринку.
- **Синхронізація сигналів:** Вхід у позицію дозволено при підтвердженні імпульсу на таймфреймах (MACD, RSI, BB, VWAP).
- **Smart DCA (Momentum Breakout):** Для захоплення сильного імпульсу (особливо по SOL та BTC): 25-30% купується по маркету (Market Buy), а 70-75% виставляється лімітною сіткою нижче ціни.

2. Position Sizing (Динамічний розрахунок лота та Ризик-менеджмент)
- **Масштабування ордерів:** Базовий розмір ордерів розраховується пропорційно поточному балансу (~650k VST):
  - SOL: 10–50 SOL.
  - BTC: 0.1–1.0 BTC.
  - XRP: 10,000–100,000 XRP.
- **Order TTL (Time-to-Live):** Задля вивільнення маржі, система скасовуватиме лімітні DCA-ордери, якщо ціна віддалилася від них більше ніж на 2.0%.

3. Take-Profit / Harvesting Protocol (Логіка виходу та розторгування)
- **Breakeven Lock (Авто-беззбиток):** Як тільки Unrealized PnL досягає +1.0%, система виставляє умовний стоп-ордер на рівні входу + 0.1% (Breakeven + комісія).
- **Зустрічні Short-ордери та BingX Bug Protection:** Відкриття зустрічних SHORT-позицій на вихідних імпульсах ціни дозволено при виснаженні тренду (`RSI > 70` / `Ask Walls`) з `reduceOnly=True`.
- **Liqmap Front-running TP:** Тейк-профіт розміщується на 0.1% раніше за магніти шорт-ліквідацій для гарантованого виконання.

4. Safety / Emergency Rules (Резервний план та Захист)
- **Auto-Stop is OFF:** Жорсткі апаратні стоп-лоси вимкнені.
- **Заборона пасивних замків:** Створення глухих хедж-замків (1-до-1) заборонено.
