## 0. КОНТЕКСТ (коротко)

Модуль tools/orderflow/collector.py збирає live стакан+трейди BTC з Bybit (без ключа)

## 1. ЩО ЗЛАМАНО (факт, з дебагу)

Поточний writer_loop (файл tools/orderflow/collector.py) при ротації видає:
```
[writer] -> rot_20260720_111804_243.jsonl
[writer] rotated -> rot_20260720_111804_243.jsonl (size=0.0MB)   <- повторюється!
FILES: 1
rot_20260720_111804_243.jsonl: 816B lines=6
```
Дві баги:
1. **НЕ унікальне ім'я при ротації.** `_next_path()` повертає той самий шлях
   (суфікс `_%Y%m%d_%H%M%S_%f` чомусь збігається або не додається унікальність)
   → замість нового файлу пише в той самий. Треба гарантовано УНІКАЛЬНЕ ім'я
   (напр. додати лічильник ротацій або monotonic counter, а не лише таймстемп).
2. **Ротація спрацьовує на ПУСТОМУ файлі (size=0.0MB).** Логіка `size` неправильна:
   або `size` ініціалізується значенням до запису, або не накопичується між записами,
   або умова `size >= max_bytes` перевіряється до того, як size оновився.
   Має бути: лічильник байтів зростає ПІСЛЯ кожного `f.write`, і ротація лише коли
   він реально перевищив поріг (або часовий інтервал пройшов).

## 2. БАЖАНА ПОВЕДІНКА (spec)

У writer_loop(queue, base_path: Path, rotate_minutes: int = 60, max_bytes: int = 2_000_000_000):
- Пише JSONL рядки з черги (як зараз: `f.write(json.dumps(item)+"\n"); f.flush()`).
- Ротація створює НОВИЙ файл, коли: (а) минув `rotate_minutes` хв від попередньої
  ротації, АБО (б) поточний файл перевищив `max_bytes`.
- Кожен новий файл має УНІКАЛЬНЕ ім'я (не перезаписувати попередній).
  Рекомендація: `f"{base_path.stem}_{counter:03d}_{timestamp}.jsonl"` де counter —
  монотонний лічильник ротацій у сесії, timestamp — UTC.
  (Не покладатись лише на мілісекунди — вони можуть збігатись у циклі.)
- `size` лічильник: ініціалізувати 0 для НОВОГО файлу, збільшувати на `len(json)+1`
  ПІСЛЯ запису кожного рядка. Ротація лише якщо `size >= max_bytes`.
- При None (маркер завершення) — закрити поточний файл і вийти.
- Залишити print-логи: `[writer] -> <path>` на старті, `[writer] rotated -> <path> (size=X.XMB)`.
