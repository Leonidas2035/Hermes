# HERMES TRADING DNA v3.0 — QUANTUMEDGE MANIFESTO

### 📋 ОНОВЛЕНІ ПРАВИЛА ВЛАСНИКА (HERMES TRADING DNA v3.0)

**1. Trigger Condition (Умови входу та мікроструктура)**
* **Синхронізація індикаторів:** Вхід у позицію дозволяється виключно при збігу сигналів базових індикаторів (MACD, BB) та успішному проходженні `sigtest`.
* **Фільтр Справедливої Ціни (VWAP):** Набір LONG-позицій має найвищий пріоритет, коли ціна знаходиться нижче денного VWAP (Undervalued Zone).
* **Снайперський Вхід (StochRSI):** Для визначення ідеальної точки входу лімітних DCA-ордерів або старту мікро-скальпів використовується виключно StochRSI (значення < 20 для локального дна, > 80 для локальної вершини) на таймфреймах 5m/15m.
* **Liqmap-Driven Entry:** Вхід здійснюється лише за умови, що відстань до найближчого пулу ліквідацій (згідно з `liqmap_latest.json`) становить ≤ 2%.
* **Smart DCA (Momentum Breakout):** Для захоплення імпульсу вхід розбивається: 25-30% виконується миттєво по маркету (Market Buy), а 70-75% виставляється лімітною сіткою нижче ціни на базі ATR.

**2. Position Sizing (Динамічний лот та Захист маржі)**
* **Пропорційне масштабування:** Базовий розмір ордера залежить від балансу: XRP (10,000–100,000), BTC (0.1–1.0), SOL (10–50).
* **Dynamic Exposure (Функція Згасання):** Жорсткі блокування відключені. Якщо вільна маржа падає нижче 40%, розмір кожного наступного DCA-ордера експоненційно зменшується (Decay Function). Це дозволяє залишатися в стакані навіть біля зон ризику, не спалюючи баланс.
* **Order TTL (Time-to-Live):** Лімітні DCA-ордери автоматично скасовуються для вивільнення маржі, якщо ціна віддалилася від них більше ніж на 2.0% і вони не виконалися протягом 1 години.

**3. Take-Profit / Harvesting Protocol (Фіксація та Розторгування)**
* **Абсолютна заборона збитків:** Жодна збиткова позиція (uPnL < 0) ніколи не закривається вручну.
* **Breakeven Lock (Авто-Беззбиток):** При досягненні позицією Unrealized PnL +1.0%, негайно виставляється умовний стоп-ордер на рівень `Average Entry + 0.1%` (фіксація комісії). Прибуткова угода не має права перетворитися на збиткову.
* **Парний Harvesting (Обхід багу BingX):** Відкриття SHORT-ордерів дозволено ВИКЛЮЧНО для скорочення існуючої LONG-позиції на виснаженні тренду (Ask Walls / RSI > 70). Для обходу помилок біржі (109420/109400) всі шорт-ордери надсилаються суворо з параметром `reduceOnly=True`. Нарощування зустрічної позиції заборонено.
* **Liqmap Front-running TP:** Тейк-профіт розраховується за ATR і розміщується на -0.1% перед найближчою Ask-стіною або магнітом ліквідацій (випередження натовпу).

**4. Safety / Emergency Rules (Резервний план)**
* **Auto-Stop is OFF:** Апаратні стоп-лоси вимкнені. Ризик контролюється через ліквідність та DCA.
* **Атакуючий Трейдинг (Anti-Lock):** Створення пасивних замків 1-до-1 (Hedge Locks) суворо заборонено. Це архітектурна помилка. Будь-який зустрічний ордер мусить мати активний Тейк-Профіт.
* **Drawdown Micro-Scalping (Резервний план):** Якщо дистанція до ліквідації падає < 3 ATR або вільна маржа < 30%, система зупиняє агресивний набір DCA. Залишки вільної маржі використовуються для бліц-скальпінгу (за сигналами StochRSI на 5m) всередині каналу. Весь реалізований прибуток від цих мікро-угод автоматично йде на часткове перекриття (гасіння) збиткової основної позиції.
